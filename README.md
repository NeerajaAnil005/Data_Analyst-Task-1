# Netflix Data Cleaning Project

## Overview

This project focuses on cleaning and preprocessing the Netflix Movies and TV Shows dataset using Python and Pandas.

## Tasks Performed

* Checked missing values
* Filled null values
* Removed duplicate records
* Standardized column names
* Converted date formats
* Cleaned text data
* Saved cleaned dataset

## Tools Used

* Python
* Pandas
* NumPy

## Files Included

* `data_cleaning.py` → Python script for data cleaning
* `cleaned_netflix_dataset.csv` → Final cleaned dataset
* `README.md` → Project description

## Outcome

The raw dataset was successfully cleaned and prepared for further analysis and visualization.
